# Meine Tools

Übersicht über alle Tools, im Design der Familienkasse. Eine einzige Datei: `index.html`.

**Neues Tool hinzufügen:** in `index.html` in der Liste `TOOLS` einen Eintrag ergänzen (Adresse, Emoji, Kategorie, Name, Text auf Deutsch und Englisch).
`feature: true` macht daraus die große schwarze Karte oben.

Vercel veröffentlicht jede Änderung auf `main` automatisch.
